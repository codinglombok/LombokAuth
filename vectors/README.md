# Vectors

`lombokauth-vectors-v1.json` is the cross-language test contract for LombokAuth.

- SHA-256: `9edfc13e90a369e116c04e6ccff5df53e43132e2df94a6d45cacf772b2513488` (must equal the hash in `docs/SPEC_LombokAuth_v0.1.0.md`).
- Generated by `scripts/gen-vectors.mjs`. Group `golden`: expectations are written by hand, copied from RFC 4226 appendix D, RFC 6238 appendix B and RFC 4648 section 10, or built with `node:crypto` (JWT tokens and PBKDF2 hashes), then matched against the TypeScript port during generation. Group `generated-regression`: seeded random inputs, with expectations from the TypeScript port confirmed by the Rust port.
- Every case calls the function `fn` with `args`; `expect` has the form `{ "result": ... }` or `{ "error": code }`.
- Every claimed port MUST run every case.
- Count: 381 cases (211 golden cases with hand-written, RFC or `node:crypto` expectations, 170 generated regression cases).
